# MiniSistema de Gestión de Inventario

Prueba técnica: API REST (C# .NET 8 + PostgreSQL) y frontend React.

## Estado
En desarrollo — Fase 1 (preparación).

## Requisitos
- .NET 8 SDK
- PostgreSQL 16+
- Node 20+

## Branch flow

- `main`: stable code, only receives the final PR.
- `develop`: integration branch, receives one PR per phase.
- `feature/*`: one branch per phase of the project.
